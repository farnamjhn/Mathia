        Transcription prompt
        
    
        Paste this into a vision model as the first message or system prompt, then attach photos
      of the pages. Copy its answer with the code block's own copy button, so no $
      is lost, and save it as a .md file. If formulas still arrive without their
      $, Options → Fix Markdown repairs the file.
        
  
        
  
  
        
    
    
  
        
        


  
        
    
        Detection settings

      writes a file you can also use with mathia --config.

      is kept on this computer and is never shown again.
